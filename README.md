# Yalla

A personal app for learning Arabic from zero: reading and writing the formal
alphabet, and speaking Egyptian Arabic. Installs to the iPhone Home Screen and
works offline. Progress is stored on the device only.

- `src/data/letters.ts` — the 28 letters, their sounds, shapes and example words
- `src/data/lessons.ts` — Egyptian speaking lessons and the lesson order
- Content the author was unsure of is flagged `check: true` and shown as "Check this"

```bash
npm install
npm run dev
npm test
```
